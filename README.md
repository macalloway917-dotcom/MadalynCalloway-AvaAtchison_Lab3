# Tip Calculator
## Description
A simple C++ console program that converts centimeters to inches, 
kilograms to pounds, and celsius to fahrenheit.
## How to Run
1. Open the project folder in Visual Studio.
2. Press Ctrl+F5 to build and run.
3. Select conversion when prompted (1, 2, or 3).
4. Enter number to convert when prompted.
## Sample Input / Output
Input: Conversion Selection: 3 Number: 30
Output: Conversion: 86
